# KIWI4 Open Source Software Release

Welcome to the KIWI4 Open Source Software (OSS) release repository.

This repository is published by **IgnitionDL** to fulfill the source code disclosure obligations of the open source software used in the KIWI4 firmware, in accordance with the applicable open source licenses.

---

# Overview

The KIWI4 firmware incorporates numerous third-party open source software components distributed under licenses including GPL, LGPL, Apache, BSD, MIT and other permissive licenses.

This repository contains:

- Source code for components modified by IgnitionDL
- Patches applied to upstream projects (where applicable)
- Third-party notices and license information
- References to upstream projects for unmodified components
